Widget del Organizador

Vista rápida del día en la pantalla de inicio del iPhone, con Scriptable.

  1. Instala Scriptable desde la App Store.
  2. Pulsa Copiar el instalador. En Scriptable, crea un script nuevo con +, pega y pulsa ▶.

    Para actualizar el widget en el futuro, vuelve a ejecutar este instalador.

  3. Abre el script Organizador que aparece y pega el enlace de organizador.json (en OneDrive: Compartir → Copiar vínculo).
  4. Mantén pulsada la pantalla de inicio → + → Scriptable → elige el tamaño. Después mantén pulsado el widget → Editar widget → Script: Organizador.
Si el instalador no funciona: copiar el widget completo

Copia todo el código, pégalo en un script nuevo de Scriptable y llámalo «Organizador».
